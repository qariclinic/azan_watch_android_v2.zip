# اذان واچ — ایندرائیڈ پروجیکٹ (ورژن 2)

یہ مکمل ایندرائیڈ پروجیکٹ ہے (WebView ایپ)۔ تمام فائلیں ایپ کے اندر موجود ہیں: adhan لائبریری، نستعلیق فونٹ، اذان کی آواز، آئیکن۔ انٹرنیٹ کے بغیر چلتی ہے۔

## APK بنانے کا آسان طریقہ (GitHub Actions)
1. github.com پر نیا ریپوزٹری بنائیں اور اس زپ کی تمام فائلیں (بشمول چھپا ہوا فولڈر `.github`) اپ لوڈ کریں۔
2. شاخ `main` پر پُش ہوتے ہی خودکار بلڈ شروع ہو جائے گا (یا Actions ← Build APK ← Run workflow)۔
3. بلڈ مکمل ہونے پر اسی صفحے کے آخر میں Artifacts سے `AzanWatch-APK` ڈاؤن لوڈ کریں؛ اس کے اندر `app-debug.apk` ہے۔
4. فون میں انسٹال کرتے وقت "نامعلوم ذرائع سے انسٹال" کی اجازت دیں۔

## متبادل: Android Studio
فولڈر کو Android Studio میں کھولیں (JDK 17)، Sync ہونے دیں، پھر Build ← Build APK(s)۔

## ایپ میں کیا ہے
- گھڑی، پانچ نمازیں + طلوعِ آفتاب، اگلی نماز کا الٹی گنتی
- ہجری (فرق کی ترتیب کے ساتھ)، شمسی اور عیسوی تاریخ
- شہر کی فہرست یا GPS، حساب کا طریقہ، عصر حنفی/شافعی
- اذان کا ٹیسٹ بٹن، اپنی آڈیو فائل، رنگوں کی تبدیلی؛ تمام ترتیبات محفوظ رہتی ہیں
- ایپ کھلی ہو تو اسکرین آن رہتی ہے

## حد
اذان صرف تب بجتی ہے جب ایپ کھلی ہو (پس منظر میں الارم/سروس شامل نہیں)۔

## ویب ورژن
فولڈر `app/src/main/assets/www` کو اپنی HTTPS ویب سائٹ پر رکھ دیں تو یہی PWA کے طور پر بھی چلے گا۔
